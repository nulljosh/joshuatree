## Try it

- **Browser:** [joshuatree.jaybulb.com/?demo](https://joshuatree.jaybulb.com/?demo)
- **Pi 4:** `tools/flash-pi.sh` ([steps](docs/GUIDE.md#raspberry-pi))
- **Build:** `brew install lld qemu`, then `make run`
