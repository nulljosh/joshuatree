Where it's at

On the roadmap: Split kernel.c into per-subsystem files; Rich document app; Native code editor and package tool.

Joshua Tree is a real graphical desktop built from scratch: its own kernel, filesystem, and network stack, a working terminal, 25 apps, and a Chat app that talks to Samantha, our own small language model, and acts on what you say: a reminder, a note, an app opened, the weather, today's calendar. You can boot the actual kernel above right now, live in your browser, no download. It's free, open source, and headed toward a 1.0 release and real hardware next.
