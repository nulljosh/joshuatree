An operating system, from scratch

No Linux under this

Its own desktop. Its own network stack. Its own text editor.
Written from nothing, boots on real hardware rules.

Own memory manager. Own filesystem. TCP built from raw Ethernet frames. The desktop runs real apps, the editor writes to a real disk, and one command talks to a local LLM. Nothing faked.

Named for the tree that survives the Mojave on nothing. And the album. And me.

Where it's at

What

A whole operating system. Kernel, desktop, windows, network stack, 15 apps. Every layer written here, nothing borrowed.

Who

Me, solo, pairing with Claude. No team, no funding, no company.

When

Started August 2026. 37 versions since, each one shipped only after it was actually proven working, not just compiling.

Why

I already talk to an AI to build things. I want that native to the machine, not bolted onto someone else's OS.

Where it's going

Next: a real syscall interface, so programs can target this thing. That's 1.0. Then voice control, then booting on actual hardware instead of an emulator.
