Joshua's kernel, built from nothing

What you just booted

No macOS, no Linux underneath it. Written from scratch,
with its own network stack, its own web server, and a real conversation with an LLM.

It boots, manages its own memory, runs a filesystem it wrote the driver for, and talks over a real network stack built from raw Ethernet frames up: ARP, DNS, TCP, a browser-shaped HTTP client, its own tiny web server, and a shell command that holds a real conversation with an LLM. This is the real thing, not a mockup of where it's headed.

Named Joshua Tree, renamed from a plain "os". The tree survives the Mojave on almost nothing, built the same way this kernel is. Also a nod to the U2 album, and my own name.

How far I've gotten

Why

I already talk to Claude and get it to build things. I want an OS that does that natively, not bolted onto macOS.

How

One real piece at a time: interrupts, memory, a filesystem, graphics. No shortcuts, no borrowed kernel.

Where it's going

Real graphics, a font renderer, and its own apps running natively, all on something I wrote myself.
