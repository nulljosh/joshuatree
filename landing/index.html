Introducing Joshua Tree.

Click or tap. It's really running.

What

A whole OS. Kernel, desktop, terminal, network stack, 18 apps, live weather. Runs at 1920×1080. Nothing borrowed.

Who

Started solo, pairing with Claude. Open source, open to anyone who wants to add to it.

When

Started August 2026. 64 versions since, each shipped only once proven working.

Why

Already talking to AI to build things. That belongs native to the machine, not bolted onto someone else's OS.

Where it's going

A real syscall gate and ring-3 tasks just shipped. Real user accounts next, now that there's something to hang them on. Then voice control. Then real hardware. Next stop, Keys View.

Where it's at

Own memory manager. Own filesystem. TCP built up from raw Ethernet frames, not borrowed from anything underneath. Named for the tree that survives the Mojave on nothing, the same one Mormon settlers thought looked like a man reaching skyward. Open for whoever wants to help it grow, no climbing permit required.
