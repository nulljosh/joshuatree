# Landing mark log

Every minor version refreshes the mark above the landing footer, one step at a time. Files: `landing/mark-tree.svg` (ink) and `landing/mark-roots.svg` (clay), stacked as CSS masks so they follow the page theme. Built with the `logo-refresh` skill.

- 1.3: the engraved badge traced to clean vector lines, sky hatching and small text dropped, window buttons, power-symbol sun and prompt added.
- 1.4: new mark. The engraved Joshua tree on its own, a ground line, and circuit-trace roots ending in solder pads: an operating system grown from scratch. Two colors, ink and clay. Poster: `docs/mark-1.4.png`.
